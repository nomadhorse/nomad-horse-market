NOMAD HORSE MARKET — MVP
========================

Arquivos:
- index.html
- styles.css
- app.js
- manifest.json
- sw.js
- icon-192.png
- icon-512.png
- nomad-horse-logo.png

COMO TESTAR
1. Abra index.html em um servidor web.
2. No GitHub Pages, coloque esta pasta no seu repositório.
3. Para funcionar como PWA instalável, acesse por HTTPS (GitHub Pages já fornece HTTPS).

O QUE JÁ FUNCIONA
- Compra: cadastro de interesse.
- Venda: cadastro de veículo e aprovação no painel.
- Fabricação: captação de novos projetos.
- Serviços: captação de manutenção/reformas.
- Marketplace com filtros.
- Painel local com status dos leads.
- Backup JSON.
- Instalação como PWA quando hospedado por HTTPS.

LIMITAÇÃO DESTA VERSÃO
Os dados ficam no localStorage do aparelho/navegador. Para produção é necessário:
- banco de dados online;
- login/autenticação;
- painel administrativo protegido;
- upload real de fotos/vídeos;
- notificações;
- regras de comissão/intermediação;
- termos de uso, política de privacidade e LGPD;
- gateway de pagamento apropriado, se houver transação dentro da plataforma.
